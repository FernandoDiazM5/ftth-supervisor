# FTTH Supervisor Pro (app instalable)

App de supervisión FTTH (WIN) que se instala en el celular. Los datos se guardan en tu Google Sheet.

- Abrir / instalar: https://fernandodiazm5.github.io/ftth-supervisor/
- La primera vez pide la **clave (token)** del Sheet en Ajustes › Conexión. La clave no está en este código.
- Funciona sin señal: lo guardado se sincroniza al volver la conexión.

Estos archivos se generan con `build.py` del proyecto; no se editan a mano.
